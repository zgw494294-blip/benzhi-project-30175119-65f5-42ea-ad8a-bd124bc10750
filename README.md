# 方言语料授权发布工作台

这是面向地方语言档案团队的单机 Web 应用。档案员可建立一份方言语料捐赠案、录入有序片段并执行本地敏感信息扫描；贡献者逐项确认研究、教学与公开展示用途；伦理复核员可定向退回整改或批准。批准后系统冻结规范化发布清单，签发带完整性哈希的一次性发布凭据，并提供审计时间线和独立校验。

应用使用 Go 原生 HTTP 页面与同源 JSON API，不需要 Node 构建链。数据保存在本地 SQLite 文件中，不连接外部业务系统。

工作台在同一案件流程中支持：

- 最多 100 条草拟片段的批量原子录入、候选级错误汇总、勾选撤销与完整顺序重排；
- 带有序片段明细和规范化 `scopeDigest` 的同意核对、用途影响提示及可持久化只读回执；
- 敏感规则复跑差异、完全匹配候选的人工处置继承，以及最多 200 项候选的批量原子处置；
- 复核退回快照、定向整改任务完整性检查和跨轮次整改轨迹；
- 发布凭据粘贴式独立校验，逐项定位凭据身份、版本、发布清单、同意、批准与完整性哈希异常。独立校验为只读操作，不改变案件版本或审计时间线。

## 构建

```sh
go build ./cmd/server
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`，默认数据库为当前目录的 `dialect-release.db`：

```sh
go run ./cmd/server
```

可以显式指定监听地址和数据库路径：

```sh
go run ./cmd/server -addr=127.0.0.1:19123 -db=./data/dialect-release.db
```

也可设置 `PORT` 为端口号，此时在没有显式 `-addr` 时监听 `127.0.0.1:<PORT>`。浏览器打开服务地址即可完成建案、同意、扫描、处置、复核、发布与校验。

## 测试与自检

运行全部回归测试：

```sh
go test ./...
```

真实 HTTP 自检会使用内存 SQLite，在指定回环地址完成批量片段、同意回执、扫描、批量处置、批准、发布和独立凭据校验流程并主动退出：

```sh
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```
